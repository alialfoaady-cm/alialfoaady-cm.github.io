Clip Review Tool

A personal tool for creating and reviewing short video clips for my own social media accounts.

How it works

  1. The tool runs on the owner's own computer and finds clip-worthy moments in livestreams.
  2. It edits them into vertical short videos and sends them to the owner's private Discord server for review.
  3. Clips the owner approves are uploaded to the owner's own channels, including YouTube (via YouTube API Services) and TikTok.

This tool is not offered to the public and has a single user: its owner.
